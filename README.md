# Escape Room

In this repository i implemented a python class that represent a room of an escape game for Quandela aptitude test.

## Instruction
### Write a Python class representing a room in an escape game. Rooms may contain objects, keys, and doors leading to other rooms. Implement methods to:
  a.	move between rooms, 
  b.	pick up and use items, 
  c.	unlock doors, 
  d.	display the current state of the game.
Ensure that instances of your class produce human-readable output when using print(). Additionally, provide code to test your class functions and adhere to the PEP 8 – Style Guide for Python Code.
